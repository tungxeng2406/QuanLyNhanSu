# Database Design

## Configuration

- Local/dev: H2 file mode, `jdbc:h2:file:./data/hrdb;AUTO_SERVER=TRUE`.
- Test: H2 in-memory, `jdbc:h2:mem:hrdb-test;DB_CLOSE_DELAY=-1`.
- `schema.sql` creates tables, constraints and indexes.
- `data.sql` runs after schema and inserts 50 deterministic rows only when `employees` is empty.
- Production does not run demo seed.

## employees table

```sql
id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY
employee_code VARCHAR(50) NOT NULL UNIQUE
full_name VARCHAR(150) NOT NULL
gender VARCHAR(20)
date_of_birth DATE
phone VARCHAR(20)
email VARCHAR(150)
```

## Constraints and indexes

- Unique `employee_code`.
- Indexes for employee code, full name, gender/date of birth, phone and email as query volume requires.

## Search strategy

- `employee_code`, `full_name`, `phone`, `email`: case-insensitive LIKE contains.
- `gender`, `date_of_birth`: exact equality.
- Multiple non-empty conditions use AND.
- Seed SQL is idempotent with `WHERE NOT EXISTS (SELECT 1 FROM employees)`.
